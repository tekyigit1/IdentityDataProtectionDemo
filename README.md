IdentityDataProtectionDemo

Bu proje, ASP.NET Core Web API kullanılarak kullanıcı yönetimi ve veri koruma (Identity + Data Protection) konularını uygulamalı olarak göstermektedir.

📌 Özellikler

Entity Framework Core Code First yaklaşımı ile User tablosu oluşturma

Email ve Password alanları için Model Validation ([Required], [EmailAddress])

PasswordHasher sınıfı ile şifrelerin hash’lenerek veritabanında saklanması

Swagger üzerinden register ve users endpoint’lerinin test edilmesi

🗄️ Kullanılan Teknolojiler

ASP.NET Core 8.0 Web API

Entity Framework Core (SQLite provider)

Swashbuckle (Swagger UI)

Microsoft.AspNetCore.Identity
